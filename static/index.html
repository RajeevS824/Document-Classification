A sub-folder named after the file is created in the output folder, with one folder per document type (for example aadhaar/aadhaar_document.pdf) and a document-wise <file name>.json next to it. PNG, JPG, TIFF and DOCX files are converted to PDF first. Password-protected PDF and Word files ask for the password.

Configuration

IMAGE_WEIGHT / OCR_WEIGHT: how much the image model and the OCR keywords count in the final score. UNKNOWN_THRESHOLD: a page whose best score is below this becomes UNKNOWN. REVIEW_MARGIN: if the top two types are closer than this, the page is marked REVIEW REQUIRED. Changes apply to the next job.

Results are evidence for review, not a guarantee; check uncertain items manually.
